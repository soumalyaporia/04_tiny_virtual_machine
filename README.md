# Project 4 — Tiny Virtual Machine

This project executes the line-oriented intermediate code generated by Project 3. It includes both a Python VM with optional tracing and a C VM for demonstrating a lower-level implementation.

## TAC format

```text
0000: DECL x
0001: CONST 7
0002: STORE x
0003: LOAD x
0004: CONST 3
0005: ADD
0006: PRINT
0007: HALT
```

The VM maintains a program counter, an operand stack, a variable table, and an output stream. Arithmetic and comparisons pop two values and push one result.

## Run the Python VM

```bash
python3 tiny_vm.py ../03_mini_compiler_tiny_c/sample.tac
```

Add `--trace` to print each fetch/decode/execute step:

```bash
python3 tiny_vm.py ../03_mini_compiler_tiny_c/sample.tac --trace
```

## Build and run the C VM

```bash
cc -std=c11 -Wall -Wextra -O2 tiny_vm.c -o tiny_vm
./tiny_vm ../03_mini_compiler_tiny_c/sample.tac
```

The C VM prints the same program output as the Python VM.

## Run the browser VM visualizer

```bash
cd web
python3 -m http.server 8004
```

Open `http://localhost:8004`. Paste TAC, load it, and use `Step` or `Run to HALT`.

## Real-life analogy

The VM is a small kitchen with a numbered recipe. The program counter is the chef’s finger on the current line, the stack is a work bowl, variables are labeled containers, and each opcode is one cooking action. A jump changes the finger to another recipe line.

## VS Code-style editor

The browser VM now provides a responsive `program.tac` editor with line numbers, opcode and number highlighting, native copy/paste, two-space indentation, smart text editing, `Format`, `Reset`, and `Ctrl/Cmd + Enter` to load TAC before stepping or running.
